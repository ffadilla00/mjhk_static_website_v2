# Phase 4D-B — Theme & Layout Architecture Audit

Audit the existing Supabase settings schema and the actual TV player visual
configuration contract before building the CMS editor.

No schema mutation is included in this pack.

Candidate 4D-B scope:
- brand/logo presentation;
- header colors;
- running-text colors;
- prayer-panel colors;
- prayer-panel side left/right;
- 65-inch display readability/layout spacing.

Out of scope until audited:
- state engine transitions;
- countdown ownership;
- prayer calculation/timing;
- dedicated-screen asset selection;
- publish/revision mutation.
